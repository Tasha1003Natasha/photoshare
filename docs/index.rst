PhotoShare
==========

PhotoShare is a FastAPI backend for photo uploads, descriptions, shared tags,
Cloudinary transformations, QR links and comments. PostgreSQL stores metadata;
Cloudinary stores images; Redis supports authentication caching and rate limits.
